03План–фактнакопительный график · план = регулярные задачи, факт = выполнено в срок

План vs факт по выбранному периоду

План (регулярные задачи) Выполнено в срок Просрочено

План — число регулярных (плановых) задач со сроком в выбранном периоде; факт — выполнено в срок; просрочено — не в срок. Обращения (заявки жильцов) в план–факт не входят. Данные суточные, агрегируются по выбранному календарному периоду.

Проверки качества (survey)

Модуль недоступен. Опросы качества не входят в тариф проекта Bruno. При появлении данных здесь будет деление «довольные (4–5) / недовольные (1–3)» и распределение оценок.

LIVE-версия — реальные агрегаты Bruno. Данные из data.json.gz (fallback data.json), файл формирует робот build-data.yml (GitHub Actions, ежедневно). План–факт считается по регулярным (плановым) задачам: план — число запланированных задач, факт — выполнено в срок; обращения в план–факт не входят. Эффективность = выполнено / (выполнено + пропущено + предупреждения). Виды работ, замечания и качество зависят от прав токена — модули оживут после их выдачи.
