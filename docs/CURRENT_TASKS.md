## Поведение

Раздел «Текущие»: название, папка, приоритет P1/P2/P3, дата и время по Москве,
один исполнитель из активных пользователей. Поиск исполнителя по имени либо
зарегистрированному email. Самостоятельной регистрации по адресу нет.
Список отсортирован по сроку; при равном сроке — по приоритету. Просроченные
невыполненные задачи выделены; выполненные находятся в раскрываемой группе.
Кружок закрывает без приёмки. Повторное нажатие возвращает в работу.
История сохраняет автора, изменения, закрытие, возврат и время. При закрытии
другим сотрудником отображается «!». Время и автор закрытия задаются сервером.

Каждый создаёт и назначает задачи. Обычный сотрудник видит свои назначения и
созданные им задачи, закрывает только назначенные ему. Автор, руководитель и
модератор редактируют открытые задачи. Руководитель и модератор видят все и
могут закрыть любую. У них есть «Все задачи / Только мои».
«Мои задачи» разделены на «Долгосрочные / Текущие». Общие папки используются
обоими разделами. Непустую папку нельзя удалить и при наличии текущих задач.
Архивирование сохраняет прежнюю семантику: задачи доступны через общий список.

## Сервер и почта

Новые файлы для Apps Script: Current.gs и CurrentMail.gs. Всего семь файлов:
Code.gs, Core.gs, Status.gs, Access.gs, Current.gs, CurrentMail.gs, appsscript.json.
После отдельного разрешения setup() добавит лист CurrentTasks с id/data_json.
Новая схема не изменяет существующие строки долгосрочных задач.
На Pages вместе с planner.html нужен shared/current.js.

Уведомления о назначении и изменении срока сохраняются в очередь вместе с
задачей. installTriggers() добавляет проверку очереди и напоминаний раз в пять
минут. Настройки shortAssign, shortReschedule, shortReminder индивидуальны;
включены по умолчанию. Общий mail_enabled также действует. Ежедневная сводка
при подписке включает отдельно долгосрочные и текущие назначения.
За час до дедлайна отправляется одно напоминание. При назначении/переносе
менее чем за час до дедлайна отдельное напоминание не отправляется.
Закрытые задачи и неактивные получатели не получают уведомлений.

## Ограничения и проверка

Триггер не гарантирует точную минуту; квоты и задержки могут увеличить интервал.
После дедлайна отдельное часовое напоминание не догоняется. Ошибка отправки
повторяется при следующем запуске. При сбое между отправкой письма и записью
подтверждения возможно повторное письмо. Это не exactly-once доставка.
Доставка на @vtb.ru, ограничения рабочих устройств, реальный вход, Drive и
совместная работа нескольких людей требуют отдельного внешнего испытания.
Новый вход заменяет предыдущий сеанс того же пользователя (наследованное правило).
Email зарегистрированных пользователей теперь передаётся авторизованному клиенту
для согласованного поиска по почте. Сеансовые ключи и хэши не передаются.
Демо хранится только в браузере и не отправляет письма. При переполнении
хранилища показывает ошибку и откатывает изменение.

Проверки: node --test tests/current.test.js tests/architecture_v2.test.js
tests/status.test.js tests/gas_sim.test.js. Apps Script проверяется имитацией
локальной таблицы и почтового сервиса, без Google API и отправки писем.
