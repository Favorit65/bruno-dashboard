Как читать дашборд: что на что влияет

Период, Объекты и Роль пересчитывают весь дашборд (блоки 01–04). Исключение — «Обращения по объектам» и воронка: они намеренно реагируют только на период и объект, роль на них не влияет.

Обращение ≠ неплановая задача. Обращение — запрос клиента (в данных Bruno у записи заполнен feedbackID); по одному обращению может быть заведено несколько задач. Неплановая задача — любая задача вне регламента, в том числе заведённая персоналом вручную, без всякого обращения — таких большинство. Поэтому чисел три, и они разные: обращений, задач по обращениям и неплановых задач всего. Тумблер «Обращения / Неплановые задачи» в блоке «Обращения по объектам» переключает, что именно рисует график, — и одновременно переключает воронку слева, чтобы на экране не оказалось двух разных «обращений». Плашка с числом объектов следует тумблеру: объектов с неплановыми задачами закономерно больше, чем объектов с обращениями. Уникальность обращения считается в пределах суток и объекта — обращение, задачи по которому шли два дня, попадает в оба дня (та же методика, что в отчётной презентации).

Роль на объектных блоках (01–03) и в «Статистике по ролям» учитывается через апортирование задачи по её исполнителям: задача с командой — по составу команды, задача без команды (например, неплановая) — по своим прямым исполнителям. На топ зон внутри объекта (блок 02) и на часовые разрезы роль не влияет — в этих данных нет разбивки по ролям.

Тумблер «Все / Плановые / Неплановые» действует на блоки 01, 02 и «Статистику по ролям». План–факт (блок 03) всегда считается только по плановым (регулярным) задачам.

Блок 04 «Персонал» умеет считать двумя способами, переключатель — в самом блоке. «Статистика Bruno» (по умолчанию) — нативные посуточные агрегаты Bruno по сотруднику; действуют период, объект и роль, но не тумблер план/внеплан — такого разреза у Bruno нет. «Счёт по задачам» — наш пересчёт по taskPlan с делением задачи между исполнителями; действуют все фильтры, но цифры законно отличаются от нативных.

Время — общее для всех графиков. Переключатель Авто / Месяц / Неделя / День в фильтрах задаёт детализацию столбцов сразу в блоке 01, блоке 03 и «Обращениях по объектам». Стрелки ‹ › на любой карточке двигают период у всех рядов одновременно; на краю архива стрелка гаснет.

Клик — это тоже фильтр. Клик по столбцу проваливается внутрь: год → месяц → день → час, синхронно во всех блоках (плашки, дерево и блоки 02/04 пересчитываются на тот же отрезок). Путь показан крошками справа от навигатора — клик по крошке возвращает на этот уровень. Объект в блоке 02 сужает фильтр объектов; плашка роли в блоке 01 — фильтр ролей; узел дерева категорий — то же, что тумблер «Все / Плановые / Неплановые»; подпись в легенде обращений или ролей добавляет и снимает объект/роль. Всё активное перечислено чипами под фильтрами и снимается там же.
